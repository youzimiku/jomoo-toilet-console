# 九牧智控中心

> 本项目为非盈利项目，仅供测试使用。
> 与九牧（JOMOO）品牌方无隶属或合作关系，未获官方授权或背书，禁止用于商业用途。

Windows 桌面端蓝牙控制客户端，用于在测试与自用场景下替代官方微信小程序「九牧智联」操作九牧轻智能／智能马桶。程序采用 BLE 直连方式，不依赖云端服务、不依赖移动端设备、不引入额外硬件，全部指令在本机与马桶之间直接收发。

## 功能特性

**连接管理**



* 建立连接后保持会话，指令下发不重复建链，实测首帧往返时延 100–200 ms

* 每 0.5 秒轮询一次状态帧，界面状态与设备实际状态保持同步

* 连续 30 秒无操作时释放蓝牙占用，将通道让给移动端；再次操作时自动重连

* 支持手动断开与手动重连，连接状态在界面中实时呈现

**设备识别**



* 从 BLE 广播名解析设备码，匹配内置型号表（152 款），自动显示型号与系列

* 未登记设备码时回退显示「未登记机型」，连接与控制功能不受影响

**状态监视**



* 盖板、座圈、着座、座温档位、夜灯、水箱蓄水、故障状态

* 动作执行过程态：正在开合盖、正在开合圈、冲水中、蓄水中

* 故障位解析为故障名称，不使用位编号

**控制指令**



* 盖板开合、座圈升降、大冲、小冲、魔力泡

* 夜灯开关、座温三档（常温／中温／高温）、休眠

**状态联动**



* 盖板、座圈、夜灯、座温按钮的高亮跟随设备真实状态，而非本地记忆

* 冲水执行中与蓄水期间，大冲、小冲、魔力泡均不可用，蓄满后自动恢复

## 使用说明

### 连接流程



1. 确认移动端「九牧智联」小程序已退出。BLE 模块同一时刻仅接受一个中心设备，移动端占用时本程序无法连接，反之亦然。

2. 运行程序，程序自动扫描广播名以 `JOMOO_SMART` 开头的设备并建立连接。

3. 连接状态在设备卡中呈现：正在连接、已连接（附空闲倒计时）、未连接。

4. 扫描失败时按 6 秒间隔重试，累计 90 秒仍未连接则停止本轮重试。

## 技术实现

### 通信协议

协议逆向自微信小程序「九牧智联」（AppID `wxb91f4d489c21f3a9`，版本 327）下发至本机的代码，采用 FC 短帧格式。

查询帧：



```
FC 11 00 00 00 00 11 00 FC
```

设备返回 26 字节状态帧。帧结构：



| 位置            | 含义                                 |
| ------------- | ---------------------------------- |
| `[0]` / `[末]` | 帧头／帧尾，固定 `0xFC`                    |
| `[1]`         | 校验，`sum(bytes[2 .. len-2]) & 0xFF` |
| `[2]`         | 源地址，`0x01` 表示手机／上位机                |
| `[3]`         | 目标地址，`0x00` 表示马桶                   |
| `[6]`         | 命令码                                |

命令码：



| 命令码    | 十进制 | 功能          |
| ------ | --- | ----------- |
| `0x11` | 17  | 状态查询        |
| `0x17` | 23  | 休眠          |
| `0x33` | 51  | 盖板开合        |
| `0x34` | 52  | 座圈升降        |
| `0x35` | 53  | 冲水（2 大／1 小） |
| `0x3C` | 60  | 座温档位（0／3／5） |
| `0x41` | 65  | 夜灯          |
| `0x46` | 70  | 魔力泡         |

状态帧判定与字段解析：



* 状态帧条件：`[6] == 0x30` 且长度不小于 25 字节

* `d[11]`：bit4 盖板、bit5 座圈、bit7 着座

* `d[12]`：bit0-1 冲水档位

* `d[13]`：bit0 翻圈中、bit1 翻盖中、bit7 满水

* `d[16]`：bit6 夜灯

* `d[17]`：bit3-5 座温档位

### GATT 参数



| 项目      | 值                                              |
| ------- | ---------------------------------------------- |
| 服务 UUID | `0000ffe0-…`                                   |
| 特征 UUID | `0000ffe1-…`（Read、WriteWithoutResponse、Notify） |
| 配对      | 不需要，未配对即可读写                                    |
| MTU     | 实测 176                                         |

通信时序要求：



* 首帧必须使用 WriteWithoutResponse 写入

* 写入后订阅 Notify，等待约 600 ms 再发送第一帧，否则首帧丢失

* 断开时需完整释放 GATT 会话（退订阅 → 写 CCCD → 释放服务对象），否则设备会持续判定为被占用，短时间内不再广播

### 型号识别

广播名格式为 `JOMOO_SMART_<设备码>`，程序取尾段数字作为设备码。设备码为型号级标识，同型号各台设备取值相同；单台设备的唯一标识为其 BLE MAC 地址，程序按 MAC 缓存上次连接目标（`%APPDATA%\JomooRemote\config.json`），用于后续重连。

型号表来源于小程序 `DeviceList`，共 171 条设备记录，其中马桶 152 款（轻智能 57 款、智能 95 款），完整对照见 [兼容型号清单.md](兼容型号清单.md)。

### 代码结构

WPF /.NET 10 单窗口应用。`Ble.cs` 负责扫描、连接、收发与会话释放；`Protocol.cs` 负责帧编解码与状态位解析；`Models.cs` 为设备码到型号的映射表；`MainWindow.xaml(.cs)` 承载界面渲染、轮询与交互；`App.xaml.cs` 提供 `--shot=`、`--demo=`、`--selftest=` 参数用于离屏渲染验证与自检。

## 兼容性

**已验证机型：九牧轻智能马桶 SQ9650-SA-CJM305（设备码 231839）。** 盖板开合、座圈升降、大冲、小冲、魔力泡、夜灯、座温三档、休眠以及故障解析均已完成真机验证，功能与界面状态一致。

设备可用需同时满足以下条件：



1. 广播名以 `JOMOO_SMART` 开头

2. 服务 `FFE0`、特征 `FFE1` 存在且可写、可订阅

3. 采用本实现所用的 FC 短帧协议

型号识别正确不代表全部功能可用。不同机型配备的功能集合不同（座温、夜灯、魔力泡、脚感、自动翻盖等），设备不具备的功能对应按钮点击后无响应，属预期行为。

以下 8 款设备在小程序能力表中标记为 `useLightSmartToiletDiferentProtocol`，协议与本实现不同，不建议直接套用：JZT430（288008）、SQ9760（283353）、SQ9761（276756／276757）、ZQ6760（255669）、SQZT700（289733）、ZJM188（289313）、MZQ5110-S01（288649）。
